# Actividad 1 - Ejercicios Prácticos de Programación Web

Repositorio que reúne los ejercicios prácticos desarrollados para la **Actividad 1 del Tema 2**, enfocados en el aprendizaje y aplicación de fundamentos de HTML5, maquetación y estilos con CSS3, y dinamismo básico con JavaScript.

El proyecto cuenta con una página principal (`index.html`) que funciona como menú interactivo hacia cada práctica, y cada página incluye un enlace directo para regresar al inicio.

---

## Contenido de los Ejercicios

* **Ejercicio 1: Encabezados y parrafos:** Estructuración básica de títulos (`<h1>` a `<h6>`) y bloques de texto.
* **Ejercicio 2: Parrafos y formato basico:** Aplicación de formato y estilos directos de texto.
* **Ejercicio 3: Enlaces simples:** Creación y navegación mediante hipervínculos (`<a>`).
* **Ejercicio 4: Imagenes basicas:** Inserción y atributos de imágenes en documentos web.
* **Ejercicio 5: Combinando texto y enlaces:** Integración combinada de texto, enlaces y tablas con celdas fusionadas (`rowspan`).
* **Ejercicio 6: Secciones semanticas basicas:** Maquetación con etiquetas semánticas de HTML5.
* **Ejercicio 7: Listas Anidadas:** Estructuración de recetas mediante listas ordenadas (`<ol>`) y desordenadas (`<ul>`) anidadas.
* **Ejercicio 8: Horario de clases:** Maquetación avanzada de tablas con horarios universitarios y estilos CSS externos.
* **Ejercicio 9: Formulario de contacto:** Diseño responsivo de formulario accesible con variables CSS (`:root`), Grid y validaciones HTML5.
* **Ejercicio 10: Conversor celsius a fahrenheit:** Calculadora interactiva de temperatura mediante manipulación del DOM con JavaScript, validación numérica y salida en campo `readonly`.

---

## Tecnologías Utilizadas

* **HTML5:** Marcado semántico, formularios y tablas.
* **CSS3:** Variables globales, Flexbox, Grid y diseño responsivo.
* **JavaScript:** Manejo de eventos en el DOM y lógica de cálculo.
